# Subtask: Create web/styles/reset.css

## Summary

Create a modern CSS reset stylesheet that normalizes default browser styles to ensure consistent rendering across different browsers.

## Requirements

- [ ] Create `web/styles/reset.css` file
- [ ] Include CSS reset covering:
  - Remove default margins and padding from HTML elements
  - Set `box-sizing: border-box` for consistent sizing
  - Set base font family, size, and line-height
  - Normalize button, input, and form elements
  - Remove default list styling
  - Ensure images are responsive

## Implementation

The reset.css should follow modern CSS reset patterns, covering common elements like:
- HTML, body, and structural elements
- Typography elements (h1-h6, p, etc.)
- Form elements (button, input, select, textarea)
- Lists (ul, ol, li)
- Images and media

## Files to Update

- `web/styles/reset.css` - New CSS reset stylesheet
